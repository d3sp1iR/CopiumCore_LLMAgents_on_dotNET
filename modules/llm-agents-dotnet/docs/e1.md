# Вертикальный срез E1 — локальный профиль

Это демонстрационный профиль с синтетическими данными. Данные запусков, агентов и предложений хранятся в памяти и теряются при остановке; аутентификация, ACL, долговременность и применение изменений не реализованы. Запускайте сервисы только в доверенном локальном окружении. `/ready` остаётся 503, так как production-зависимости не реализованы.

Требуются .NET 10, работающий Ollama и модель `qwen3:4b-instruct`. Команды выполняются из корня репозитория в отдельных терминалах:

```bash
ollama serve
```

```bash
dotnet run --project modules/llm-agents-dotnet/src/CopiumCore.TestGraphApi -- --urls http://127.0.0.1:5001
```

```bash
dotnet run --project modules/llm-agents-dotnet/src/CopiumCore.Api -- --urls http://127.0.0.1:5000 --CopiumCore:Demo=true --CopiumCore:UseLocalModel=true
```

```bash
dotnet run --project modules/llm-agents-dotnet/src/CopiumCore.Console -- --settings modules/llm-agents-dotnet/src/CopiumCore.Console/settings.example.json
```

Адреса и модель можно задать настройками `Graph__Url`, `Ollama__Url` и `Ollama__Model`. Console показывает статус запуска, источники и карточку ожидающего предложения. У Graph API и агента используются два объекта: `req-17` содержит ссылку `decisionId`, а `doc-9` ссылается обратно на заявку. Runtime проверяет эти поля и `approved`, но отдельное ребро `supportedBy` пока не реализовано. Модель может вернуть `insufficientEvidence` или ошибку, если не смогла корректно выполнить сценарий: это нужно проверять фактическим прогоном.
